📋 AMBER 蛋白-配体相互作用模拟流程

本站整理 AMBER / GROMACS 模拟方法与示例。输入参数需要按体系调整；本仓库进行静态检查和分析算法回归测试，未完成真实体系的模拟验证。常规 AMBER 示例约定蛋白为 :1-237、SAM 为 :238、目标配体为 :239；QM/MM 与其他示例使用各自的编号，不能混用。运行前从最终拓扑核对原子、残基、净电荷、质子化态、盒子与力场。软件版本和依赖说明见 README。

🔬 使用 Gaussian 算 RESP 电荷

前期准备

  1. 按照标准将对接的小分子使用 DS 保存成 mol2 文件，文件中的残基名字必须正确
  2. 将 mol2 文件导入 Gaussian View 保存成 .gjf 文件

第一步：结构优化

Gaussian
%chk=SAM.chk
%nproc=30
#p B3LYP/6-31G* int=ultrafine opt freq

第二步：计算 RESP 电荷

Gaussian
--Link1--
%Chk=SAM.chk
#p HF/6-31G* Pop=MK IOp(6/33=2) IOp(6/42=6) Geom=AllCheck Guess=Read
Bash
nohup g16 < GA1.gjf > GA1.log &              # Linux下调用gaussian的命令

第三步：后处理

  1. 计算完成得到 .log 文件后，将后缀改为 .out
  2. 运行 formchk 生成 .fch 文件：
Bash
formchk SAM.chk                      # 生成.fch文件
  1. 使用 Multiwfn 的 RESP 拟合功能（菜单依版本核对），记录拟合设置、等价原子约束及净电荷；HF/MK 步骤生成 ESP 数据，RESP 是其后的拟合步骤
  2. 逐原子核对元素、名称、连接和顺序后导出 charge 文件或写入 mol2；必须检查电荷总和等于设定净电荷。不要按行号盲目覆盖，不要在 RESP 后重新运行 BCC 覆盖电荷
提示

项目标识示例：714_2_Dn_ante

💊 小分子的准备

先确定配体的化学结构、键级、质子化态、互变异构体和净电荷，再加氢。RESP 与 AM1-BCC 是两条替代路线；下面是 AM1-BCC/GAFF2 示例，净电荷必须由使用者设置，不使用默认电荷猜测。SAM 的参数适用性需要单独检查。

Bash
# 设置实际净电荷后运行，例如 export GA1_CHARGE=...; export SAM_CHARGE=...
: "${GA1_CHARGE:?请设置目标配体整数净电荷}"
: "${SAM_CHARGE:?请设置SAM整数净电荷}"
antechamber -i GA1.mol2 -fi mol2 -o GA1_ante.mol2 -fo mol2 -at gaff2 -c bcc -nc "$GA1_CHARGE"
parmchk2 -i GA1_ante.mol2 -f mol2 -s gaff2 -o GA1.frcmod
antechamber -i SAM.mol2 -fi mol2 -o SAM_ante.mol2 -fo mol2 -at gaff2 -c bcc -nc "$SAM_CHARGE"
parmchk2 -i SAM_ante.mol2 -f mol2 -s gaff2 -o SAM.frcmod
# RESP 路线：使用已验证与输入原子顺序一致的 charge 文件，替代 -c bcc：
# antechamber ... -at gaff2 -c rc -cf resp_charges.txt -nc "$GA1_CHARGE"
# 检查 frcmod 中缺失/低可信度参数、mol2 原子类型和电荷总和。
命令作用
antechamber将 mol2 转换为 AMBER 可识别的格式，分配所选 GAFF/GAFF2 力场原子类型（本例为 GAFF2）
parmchk2检查缺失的力场参数，生成 .frcmod 补充文件

🔗 拓扑文件的获取 (tleap)

将代码集合在 .tleap 文件中统一处理：

Bash
tleap -f name.tleap                           # 调用.tleap文件
tleap 脚本
source leaprc.protein.ff14SB                # 加载蛋白质力场 ff14SB
source leaprc.gaff2                          # 加载小分子力场 gaff
source leaprc.water.tip3p                   # 加载水分子力场 tip3p
set default PBRadii mbondi2                # 本例 MM/GBSA igb=2；其他模型需匹配半径

# ---- 小分子 LIG1 (GA1) ----
LIG1 = loadmol2 GA1_ante.mol2
check LIG1
loadamberparams GA1.frcmod
saveoff LIG1 GA1.lib
saveamberparm LIG1 GA1.prmtop GA1.inpcrd

# ---- 小分子 LIG2 (SAM) ----
LIG2 = loadmol2 SAM_ante.mol2
check LIG2
loadamberparams SAM.frcmod
saveoff LIG2 SAM.lib
saveamberparm LIG2 SAM.prmtop SAM.inpcrd

# ---- 蛋白质受体 ----
REC = loadpdb SeNMT.pdb
check REC
saveamberparm REC receptor.prmtop receptor.inpcrd

# ---- 复合物 ----
COM = combine {REC LIG2 LIG1}
saveamberparm COM com.prmtop com.inpcrd
charge COM

# ---- 加溶剂和离子 ----
solvatebox COM TIP3PBOX 12.0
addions2 COM Na+ 0
addions2 COM Cl- 0
saveamberparm COM com_solvated.prmtop com_solvated.inpcrd
quit
关键参数说明

solvatebox 12.0 — 溶剂盒子距离溶质最小距离 12.0 Å
addions2 Na+/Cl- 0 — 依据净电荷添加反离子中和；不等于指定盐浓度，若需生理盐浓度应另行计算并检查离子数

⚡ 体系能量最小化

3. QM/MM 设置

3.1 QM 区域定义

对于 SAM → PHB 的 SN2 甲基转移，QM 区应覆盖反应两端及其局部成键环境：

QM 区至少包含：

├── SAM 的供体硫原子与被转移甲基碳（S–CH₃）

├── PHB 的进攻氧、羧基碳及另一个羧基氧（完整局部 –COO– 共价片段）

├── 若参与质子转移或显著稳定过渡态，再纳入相应水分子/催化残基

└── QM/MM 边界选在不发生反应的共价键上，并按所用接口处理 link atom

选区原则：只含 SAM 腺苷部分并不能代替反应中心；必须确认被转移甲基碳、供体硫和 PHB 进攻氧均在 QM 区，且反应中的 C–S/C–O 键不跨越 QM/MM 边界。PHB 羧基应按实际质子化态选取完整共价片段。水、催化残基和 QM 区大小需结合反应机理及选区收敛性判断，不存在通用的固定原子数。

电荷：qmcharge 应由实际选中的 QM 原子、配体/残基质子化态及互变异构状态计算并核对；不要把底物整体形式电荷直接当成 QM 区电荷，也不要照抄示例值。

cpptraj — 查看原子编号
cpptraj -p complex.prmtop << EOF
atoms :SAM@S,CB,C* :PHB@C,O* out qm_atoms.dat
EOF

3.2 Link Atom 设置

link atom 是 QM/MM 共价边界的计算截断处理，不是体系中的真实氢原子。选取边界时应使正在断裂/形成的 C–S 与 C–O 键完整留在 QM 区；对边界上被截断的非反应性共价键，按所用 Amber/QM 接口的规则处理 link atom。

边界位置须根据实际拓扑和所选 QM 原子验证：

SAM 的 Cβ–Cγ 可作为候选截断键示例，但不是通用规定

确认 QM 侧仍包含供体 S 与转移甲基，且边界不切断反应键

PHB 若完整纳入 QM，则其内部共价键不需要 link atom

4. 平衡化 MD

4.1 分步平衡化流程

bash — 能量最小化 + 升温 + NPT 平衡
# 1. 能量最小化（仅 MM）
cat > min.in << 'EOF'
Minimization
&cntrl
  imin=1, maxcyc=5000, ncyc=2500,
  ntb=1, cut=10.0,
  ntr=1, restraint_wt=50.0,
  restraintmask=':1-300@CA,C,N',
/
EOF
sander -O -i min.in -o min.out -p complex.prmtop -c complex.inpcrd -ref complex.inpcrd -r min.rst

# 2. NVT 升温（100K → 300K）
cat > heat.in << 'EOF'
Heating
&cntrl
  imin=0, nstlim=50000, dt=0.001,
  ntb=1, cut=10.0, ntc=2, ntf=2,
  tempi=100.0, temp0=300.0, ntt=3, gamma_ln=2.0,
  ntr=1, restraint_wt=10.0,
  restraintmask=':1-300@CA,C,N',
  nmropt=1,
/
&wt type='TEMP0', istep1=0, istep2=50000, value1=100.0, value2=300.0 /
&wt type='END' /
EOF
sander -O -i heat.in -o heat.out -p complex.prmtop -c min.rst -ref complex.inpcrd -r heat.rst

# 3. NPT 平衡（逐步释放约束）
# Continue coordinates and velocities from the previous stage.
prev_rst="heat.rst"
for wt in 10.0 5.0 1.0 0.0; do
cat > eq_${wt}.in << EOF
NPT Equilibration, restraint_wt=${wt}
&cntrl
  imin=0, irest=1, ntx=5, nstlim=100000, dt=0.002,
  ntb=2, pres0=1.0, ntp=1, taup=2.0,
  cut=10.0, ntc=2, ntf=2,
  temp0=300.0, ntt=3, gamma_ln=2.0,
  ntr=1, restraint_wt=${wt},
  restraintmask=':1-300@CA,C,N',
/
EOF
sander -O -i eq_${wt}.in -o eq_${wt}.out -p complex.prmtop -c "$prev_rst" -ref complex.inpcrd -r eq_${wt}.rst
prev_rst="eq_${wt}.rst"
done

4.2 QMMM 能量最小化

在开启 QM/MM 前，对 QM 区域进行约束优化，固定溶剂和离子，放松 QM 区域构象：

Amber — qmmm1.in
explicit qmmm production run: 2ps
 &cntrl
  imin=1, 
  maxcyc=5000, 
  ncyc=2000, 
  ntc=1, ntb=1,
  ntf=1,
  ntpr=100,
  ntr=1, restraintmask='!:1-357', 
  restraint_wt=2,
  cut=8.0
  ifqnt=1,nmropt=1
  / 
  &qmmm
  qmmask=':18,25,155,158,159,218,356,357',
  qmcharge=-1,
  qm_theory='PM6',
  qmshake=0
  /
  &wt type='END' /
  DISANG=rc.RST
参数说明

imin=1 能量最小化模式；maxcyc=5000 最大 5000 步，前 ncyc=2000 步最速下降法。
ntr=1, restraintmask='!:1-357' 固定 357 号残基之后的所有原子（溶剂和离子）。
ifqnt=1 开启 QM/MM；nmropt=1 + DISANG=rc.RST 固定反应坐标约束。
此处残基号、QM 原子选择和 qmcharge=-1 都只是示例，必须按实际拓扑、边界原子和质子化态核对总电荷。该示例已使最小化与生产阶段的 qmmask 一致；若确认 218 号残基不应纳入 QM 区，则应在两处及全部伞形采样窗口中同步调整。本例最小化与生产采用同一 QM 定义以简化流程。若先用 MM 或另一 QM 模型准备初态，切换后需要在目标 Hamiltonian 下重新平衡。用于合并同一 PMF 的生产窗口须使用一致的 QM 原子集、总电荷、方法和边界处理；改变它们会改变势能面，须用相应的跨 Hamiltonian 重加权方法，不能直接套用仅去 umbrella 偏置的 WHAM。

5. 反应坐标与伞形采样

5.1 反应坐标（RC）选择

对于 SN2 甲基转移反应，推荐的反应坐标：

主反应坐标（差值坐标）：

$$\xi = d_{\text{C-S}} - d_{\text{C-O}}$$

其中：$d_{\text{C-S}}$ = SAM 甲基碳到硫原子的距离，$d_{\text{C-O}}$ = 甲基碳到 PHB 进攻氧的距离。下方脚本中的原子编号是体系/拓扑相关的示例；运行前须在实际 prmtop/PDB 中逐一确认编号映射，并检查 Amber DISANG 的 iat/rstwt=1,-1 与 PLUMED 的 dist1-dist2 都实现同一符号定义 $d(C_{methyl}-S)-d(C_{methyl}-O_{attack})$。用已知反应物和产物结构计算两项距离，确认反应物端为负、产物端为正，再生成窗口中心；不能只凭注释或窗口编号判断符号。

bash — run_wham.sh
#!/bin/bash
set -euo pipefail

# Set WHAM_BIN to the full path of the Grossfield WHAM executable.
# Inspect a sample DUMPAVE file from the installed Amber version and set
# DUMPAVE_RC_COL to the 1-based column containing the instantaneous reaction coordinate.
: "${WHAM_BIN:?Set WHAM_BIN to the full path of the WHAM executable}"
: "${DUMPAVE_RC_COL:?Set DUMPAVE_RC_COL after checking this Amber version's DUMPAVE output}"
if [[ ! -x "$WHAM_BIN" ]]; then
    echo "WHAM_BIN is not an executable file: $WHAM_BIN" >&2
    exit 1
fi
if [[ ! "$DUMPAVE_RC_COL" =~ ^[1-9][0-9]*$ ]]; then
    echo "DUMPAVE_RC_COL must be a positive 1-based column number." >&2
    exit 1
fi

# Must match kumb in setup_umb_samp.sh. With the Amber &rst parabolic term
# E = kumb*(xi-center)^2, Grossfield WHAM's 0.5*K*(xi-center)^2 uses K=2*kumb.
K_AMBER=100
K_WHAM=$(awk -v k="$K_AMBER" 'BEGIN { printf "%.10g", 2*k }')
TEMPERATURE=300
: > meta.dat

# Use the same centers and two-decimal naming as setup_umb_samp.sh.
for i in $(seq -2.0 0.10 2.0); do
    rc=$(printf "%.2f" "$i")
    raw="rc${rc}/rc${rc}_1.tra"
    prepared="rc${rc}/rc${rc}.wham.dat"
    if [[ ! -s "$raw" ]]; then
        echo "Missing DUMPAVE file: $raw" >&2
        exit 1
    fi
    # DUMPAVE columns vary by Amber version and restraint type. Select only
    # the user-verified instantaneous RC column; do not assume a universal index.
    awk -v col="$DUMPAVE_RC_COL" '
        /^[[:space:]]*#/ { next }
        NF < col { next }
        $col !~ /^[-+]?(([0-9]+([.][0-9]*)?)|([.][0-9]+))([eE][-+]?[0-9]+)?$/ { next }
        { printf "%d %.12g\n", ++n, $col }
    ' "$raw" > "$prepared"
    if [[ ! -s "$prepared" ]]; then
        echo "No numeric reaction-coordinate values found in $raw column $DUMPAVE_RC_COL" >&2
        exit 1
    fi
    printf '%s %s %s\n' "$prepared" "$rc" "$K_WHAM" >> meta.dat
done

# A distance-difference coordinate is nonperiodic, so omit WHAM's P periodicity flag.
# Grossfield WHAM is invoked directly; WHAM_BIN is the executable, not its directory.
"$WHAM_BIN" -2.025 2.025 80 0.000000001 "$TEMPERATURE" 0 meta.dat wham.txt 0 1 > wham.log 2>&1
sed '/^#/d' wham.txt | cut -f 1,2 > pmf.txt
脚本说明

run_wham.sh 的输入约定：
• 运行前必须按当前 Amber 版本和该类 restraint 的 DUMPAVE 格式检查样例文件，并设置 DUMPAVE_RC_COL 为瞬时反应坐标所在的 1-based 列；脚本不猜测列号，也不能选择窗口目标值、力或功。生成的 .wham.dat 使用“样本序号、反应坐标”两列。
• WHAM_BIN 必须指向 Grossfield WHAM 可执行文件本身。meta.dat 的力常数设为 2*kumb：只有在 Amber &rst 的能量项为 kumb*(ξ-center)^2 且与脚本中的 kumb=100 一致时，才对应 WHAM 的 0.5*K*(ξ-center)^2 定义。
• ξ 是非周期的距离差，因此命令不带周期选项 P；80 个分箱覆盖 -2.025 到 2.025 Å。
• 结果保存在 pmf.txt（两列：反应坐标 ξ 和 PMF 值）。

6.3 使用 PyMBAR 4.x 计算 PMF

下面的脚本读取 AMBER 原生方案生成的 rc-2.00/rc-2.00_1.tra 至 rc2.00/rc2.00_1.tra。运行前必须检查当前 Amber 版本的 DUMPAVE 输出，设置 DUMPAVE_RC_COL 为瞬时 ξ 的列号，并根据各窗口收敛检查设置 BURN_IN_ROWS。该脚本假设各窗口温度和未加偏置的哈密顿量相同，仅 umbrella 中心不同；如果采样 Hamiltonian 不同，必须使用完整势能重新构造 u_kn。输出的 FES 是无量纲量，代码乘以 kBT 转成 kcal/mol。FES 与时间序列去相关接口见 PyMBAR 4.x FES 文档 和 PyMBAR 4.0 时间序列文档。

Python — wham_pymbar.py (PyMBAR 4.x)
import os
import numpy as np
import matplotlib.pyplot as plt
from pymbar import FES, timeseries

# Required: inspect this Amber version's DUMPAVE format and set the
# 1-based column containing the instantaneous reaction coordinate (xi).
DUMPAVE_RC_COL = int(os.environ.get("DUMPAVE_RC_COL", "0"))
if DUMPAVE_RC_COL < 1:
    raise SystemExit("Set DUMPAVE_RC_COL to the inspected 1-based xi column.")

# Choose after checking equilibration/convergence for these windows.
BURN_IN_ROWS = int(os.environ.get("BURN_IN_ROWS", "-1"))
if BURN_IN_ROWS < 0:
    raise SystemExit("Set BURN_IN_ROWS based on the window equilibration check.")

temperature = 300.0
kB = 0.00198720425864083  # kcal mol^-1 K^-1
beta = 1.0 / (kB * temperature)
k_amber = 100.0  # Must match kumb in setup_umb_samp.sh.
k_bias = 2.0 * k_amber  # Amber &rst: k_amber*dx^2; PyMBAR harmonic form: 0.5*k_bias*dx^2.
centers = np.arange(-2.0, 2.0001, 0.10)

xi_by_window = []
for center in centers:
    label = f"{center:.2f}"
    path = f"rc{label}/rc{label}_1.tra"
    if not os.path.isfile(path):
        raise FileNotFoundError(path)

    xi_raw = np.loadtxt(
        path, comments="#", usecols=(DUMPAVE_RC_COL - 1,), ndmin=1
    )
    if BURN_IN_ROWS >= xi_raw.size - 1:
        raise ValueError(f"BURN_IN_ROWS leaves too few samples in {path}.")
    xi_raw = xi_raw[BURN_IN_ROWS:]
    if xi_raw.size < 2:
        raise ValueError(f"Too few production samples in {path}.")

    # FES assumes effectively uncorrelated input samples.
    indices = timeseries.subsample_correlated_data(xi_raw)
    xi_by_window.append(xi_raw[indices])

N_k = np.asarray([len(x) for x in xi_by_window], dtype=int)
if np.any(N_k == 0):
    raise ValueError("At least one window has no uncorrelated samples.")

# Keep samples ordered by umbrella state, matching N_k.
xi_n = np.concatenate(xi_by_window)
u_kn = beta * 0.5 * k_bias * (xi_n[None, :] - centers[:, None]) ** 2

# All windows share the same physical potential and temperature, so its
# common contribution cancels from MBAR weights. This target state has no bias.
u_n = np.zeros_like(xi_n)
edges = np.linspace(-2.025, 2.025, 81)
bin_counts, _ = np.histogram(xi_n, bins=edges)
bin_centers = 0.5 * (edges[:-1] + edges[1:])
occupied = bin_counts > 0
x_plot = bin_centers[occupied]

fes = FES(u_kn, N_k)
fes.generate_fes(
    u_n,
    xi_n[:, None],
    fes_type="histogram",
    histogram_parameters={"bin_edges": [edges]},
)
result = fes.get_fes(

7.5 误差分析与收敛检查

text — PMF 分块收敛分析
PMF 分块检查流程（方法步骤，不是可直接执行的 Python）：
1. 剔除各窗口平衡段，并估算目标可观测量的自相关时间。
2. 每个时间块都包含全部窗口的对应生产片段。
3. 对每个完整块重新运行 WHAM/MBAR，重建整条 PMF，统一自由能零点。
4. 在相同反应物盆地与候选势垒定义下计算每块的自由能差，比较块长与独立重复结果。
5. 检查区间覆盖、窗口重叠和稀疏区间；不足时延长采样，不能用有限伪概率补齐。

8. 关键注意事项

8.1 QM 方法选择

方法成本与适用性需要验证的因素
PM3 / AM1 / PM6较低成本，用于初步结构/路径探索反应能、质子转移与势垒可能有体系依赖误差；不能凭方法名确定精度
SCC-DFTB成本较低，需适用的参数集元素覆盖、参数化范围及该反应的基准误差
DFT（B3LYP、M06-2X、ωB97X-D 等）成本通常更高，应选合适基组和嵌入泛函、基组、色散、电荷分布与 QM 区收敛性；不存在通用五星排序

半经验 QM/MM 的 PMF 可用于初步探索，但不能仅凭 PM6 结果宣称定量能垒已验证。对有定量要求的结论，应在相同 QM 区、边界、净电荷和嵌入定义下，对代表性反应物/过渡态/产物构型进行更高等级 QM/MM 基准比较，并说明校准方法与不确定度；不存在适用于所有体系的通用能垒修正量。

8.2 常见错误与解决方案

问题可能原因解决方案
Gaussian 计算失败内存不足 / SCF 不收敛增加 %mem，使用 SCF=(MaxCycle=200)

5. 自由能计算（Jarzynski 等式）

单次 SMD 轨迹的功不等于自由能，需要多条轨迹并结合 Jarzynski 等式。

3.1 Jarzynski 等式：

$$\Delta G = -\frac{1}{\beta} \ln \left\langle e^{-\beta W} \right\rangle$$

其中：

  • $\beta = 1/(k_B T)$
  • $W$ 是每条轨迹的非平衡功
  • $\langle \cdot \rangle$ 表示系综平均

3.2 二阶累积量近似（需检验功分布接近高斯）：

$$\Delta G \approx \langle W \rangle - \frac{\beta}{2}\left(\langle W^2 \rangle - \langle W \rangle^2\right)$$

Python — Jarzynski 自由能估算
import numpy as np

def jarzynski_second_order(works, temperature=300):
    """
    使用二阶累积量展开计算自由能
    works: 多条轨迹的最终功值数组 (kcal/mol)
    temperature: 温度 (K)
    """
    kB = 0.001987  # kcal/mol/K
    beta = 1.0 / (kB * temperature)
    
    W_mean = np.mean(works)
    W_var = np.var(works)
    
    # 二阶累积量展开
    dG = W_mean - 0.5 * beta * W_var
    return dG

# 示例：10 条轨迹的最终功
works = np.array([15.2, 18.5, 14.8, 16.3, 17.1, 
                  15.8, 16.9, 14.5, 17.8, 16.2])

dG = jarzynski_second_order(works)
print(f"同一协议端态的自由能差近似（尚非标准结合自由能）: {dG:.2f} kcal/mol")

定量结果逐步增加独立轨迹，检查低功尾部、分块/重复不确定度和速率敏感性；固定条数不保证精度

6. 平均力势（PMF）分析

SMD 距离直方图属于时间依赖偏置下的非平衡分布，不能直接取 −kBT ln P 当作平衡 PMF。SMD 可提供路径和伞形采样窗口初态；各窗口需要单独平衡和充分采样，再以 WHAM/MBAR 去偏置并检查重叠与误差。

若采用非平衡方法，需使用相同协议下的独立平衡初态和正确的外部参数功，采用 Hummer–Szabo 重构等适用方法。Jarzynski 端态自由能差、无偏坐标 PMF 与标准结合自由能是不同对象；后者需要状态积分及几何、约束和标准态修正。

10. 注意事项

重要提示

拉伸速率影响：过快的拉伸速率会导致非平衡效应，功值偏高。建议测试不同速率（如 0.1-10 Å/ns）
弹簧参数：数值与软件偏置势定义有关，先核对 harm 与物理 k 的因子；依据反应坐标波动、积分稳定性和重构误差选择，不能把 10 或 800 当作普遍标准

2. 体系搭建：多配体体系

LiGaMD 的体系搭建不同于常规 MD 和 SMD，可采用单配体或多配体方案，初态可用于结合或解离研究，并非必须同时有一个结合配体和固定数目的游离配体。多配体数量会改变游离浓度、配体间作用与再结合统计，需要结合盒子体积和目标问题设计。下方放置脚本生成 N 个初始游离 T3Q；SAM 是辅因子，不能计入 T3Q 的 nlig。

📄 随机放置配体脚本：setup_multi_T3Q.py

Python — setup_multi_T3Q.py
#!/usr/bin/env python3
"""
setup_multi_T3Q.py
为 SeNMT + SAM + N×T3Q 体系随机放置多个T3Q配体

用法:
    python3 setup_multi_T3Q.py <SeNMT.pdb> <SAM_ante.mol2> <T3Q_ante.mol2> <pocket_center_x,y,z> [N_LIGANDS]

示例:
    python3 setup_multi_T3Q.py SeNMT.pdb SAM_ante.mol2 T3Q_ante.mol2 15.0,20.0,25.0 5

说明:
    - SAM 作为辅因子，固定在口袋中（坐标来自 SAM_ante.mol2，需已对齐到蛋白）
    - T3Q 作为被研究配体，随机放置 N 个到溶剂中
    - 自动生成 tleap.in 和 LiGaMD mdin 模板
"""

import numpy as np
import sys
import os

# ==================== 用户可调参数 ====================
BOX_BUFFER = 12.0               # 溶剂层厚度 (Å)，与 solvateoct 一致
MIN_LIG_LIG_DIST = 10.0         # 配体间最小原子-原子距离 (Å)
MIN_LIG_PRO_DIST = 5.0          # 配体-蛋白最小原子-原子距离 (Å)
MIN_LIG_SAM_DIST = 8.0          # T3Q 与 SAM 最小原子-原子距离 (Å)
POCKET_EXCLUDE_RADIUS = 18.0    # 口袋排除半径 (Å)，T3Q 初始不放这里
SEED = 42                       # 随机种子

# LiGaMD_Dual (igamd=11) 的示例阶段长度，单位为 MD steps。
# 这些是模板起点，不是对收敛或动力学精度的保证；应根据最终体系、
# GaMD 能量统计稳定性和独立重复模拟调整。ntcmd/nteb 应与 ntave 相容。
DT_PS = 0.002
NTCMD = 700_000
NTCMD_PREP = 280_000
NTEB = 27_300_000
NTEB_PREP = 280_000
NTAVE = 140_000
PRODUCTION_STEPS = 100_000_000  # 示例 200 ns；须按收敛情况调整
NSTLIM = NTCMD + NTEB + PRODUCTION_STEPS
# =====================================================

def leap_quote(path):
    """为 LEaP 输入中的文件路径加引号。"""
    return '"' + os.path.abspath(path).replace('\\', '/').replace('"', '\\"') + '"'

def verify_ligamd_template(mdin_file):
    """确认 AMBER namelist 和需人工核对的拓扑占位符都保留在模板中。"""
    with open(mdin_file, 'r') as f:
        text = f.read()

    required_markers = (
        "__FILL_T3Q_RESIDUE_MASK_FROM_FINAL_PRMTOP__",
        "__FILL_PROTEIN_ATOM_SERIAL_FROM_FINAL_PRMTOP__",
        "__FILL_T3Q_INTERNAL_ATOM_SERIAL_1_BASED__",
    )
    missing = [marker for marker in required_markers if marker not in text]
    if missing:
        raise RuntimeError(f"LiGaMD 模板缺少必填占位符: {', '.join(missing)}")
    if text.count('&cntrl') != 1 or '&pmd' in text:
        raise RuntimeError("LiGaMD 参数必须只写在一个 &cntrl namelist 中")
    if NTCMD % NTAVE != 0 or NTEB % NTAVE != 0:
        raise RuntimeError("ntcmd 和 nteb 必须按 GaMD 手册要求与 ntave 相容")
    if NTCMD_PREP > NTCMD or NTEB_PREP > NTEB:
        raise RuntimeError("ntcmdprep/ntebprep 不能大于对应阶段步数")
    if NSTLIM <= NTCMD + NTEB:
        raise RuntimeError("nstlim 必须大于 ntcmd + nteb，才能留出生产阶段")

def read_pdb_coords(pdb_file):
    """读取 PDB 中的 ATOM/HETATM 坐标"""
    coords = []
    atoms = []
    with open(pdb_file, 'r') as f:
        for line in f:
            if line.startswith('ATOM') or line.startswith('HETATM'):
                x = float(line[30:38])
                y = float(line[38:46])
                z = float(line[46:54])
                coords.append([x, y, z])
                atoms.append(line)
    return np.array(coords), atoms

def read_mol2(mol2_file):
    """读取 mol2 文件的 ATOM 段，返回坐标和原子信息"""
    coords = []
    atoms = []
    in_atom = False
    with open(mol2_file, 'r') as f:
        for line in f:
            if line.startswith('@<TRIPOS>ATOM'):
                in_atom = True
                continue
            if line.startswith('@<TRIPOS>BOND') or line.startswith('@<TRIPOS>SUBSTRUCTURE'):
                in_atom = False
                continue
            if in_atom and len(line.strip()) > 0:
                parts = line.strip().split()
                if len(parts) >= 6:
                    x = float(parts[2])
                    y = float(parts[3])
                    z = float(parts[4])
                    coords.append([x, y, z])
                    # 构造伪 PDB 格式的原子行，方便后续写入
                    atom_name = parts[1]
                    res_name = parts[7] if len(parts) > 7 else 'T3Q'
                    # 补齐到4字符的原子名
                    atom_name = atom_name[:4]
                    if len(atom_name) < 4:
                        atom_name = ' ' + atom_name if len(atom_name) == 3 else ' ' * (4 - len(atom_name)) + atom_name
                    # 构造 PDB 行
                    pdb_line = f"HETATM{len(atoms)+1:5d} {atom_name:4s} {res_name:3s}  {1:4d}    {x:8.3f}{y:8.3f}{z:8.3f}  1.00  0.00           {parts[5]:2s}  \n"
                    atoms.append(pdb_line)
    return np.array(coords), atoms

def write_pdb(coords, atoms, outfile, resid=1):
    """写入 PDB，支持修改残基号"""
    with open(outfile, 'w') as f:
        for i, (coord, atom) in enumerate(zip(coords, atoms)):
            x, y, z = coord
            # 替换残基号（第22-26列）
            new_line = atom[:22] + f"{resid:4d}" + atom[26:30] + f"{x:8.3f}{y:8.3f}{z:8.3f}" + atom[54:]
            f.write(new_line)
        f.write("END\n")

def get_center_and_radius(coords):
    """获取几何中心和最大半径"""
    center = np.mean(coords, axis=0)
    dists = np.linalg.norm(coords - center, axis=1)
    return center, np.max(dists)

def minimum_atom_distance(coords_a, coords_b):
    """计算两组原子坐标间的最小距离，避免只用分子中心漏掉原子重叠。"""
    if len(coords_a) == 0 or len(coords_b) == 0:
        return float("inf")
    delta = coords_a[:, np.newaxis, :] - coords_b[np.newaxis, :, :]
    return float(np.sqrt(np.min(np.sum(delta * delta, axis=2))))

def generate_random_position(box_center, box_size, 
                             pocket_center, pocket_radius,
                             ligand_coords, ligand_center,
                             existing_ligands, prot_coords, sam_coords,
                             min_lig_lig, min_lig_pro, min_lig_sam,
                             max_attempts=20000):
    """
    在盒子内随机生成配体位置，满足多重约束
    """
    half_box = box_size / 2.0

    for attempt in range(max_attempts):
        pos = box_center + (np.random.rand(3) - 0.5) * box_size

        # 1. 不在口袋排除区内
        if pocket_center is not None:
            d_pocket = np.linalg.norm(pos - pocket_center)
            if d_pocket < pocket_radius:
                continue

        candidate_coords = ligand_coords - ligand_center + pos

        # 2. 不与蛋白原子太近
        if prot_coords is not None and len(prot_coords) > 0:
            d_pro = minimum_atom_distance(candidate_coords, prot_coords)
            if d_pro < min_lig_pro:
                continue

        # 3. 不与 SAM 原子太近
        if sam_coords is not None and len(sam_coords) > 0:
            d_sam = minimum_atom_distance(candidate_coords, sam_coords)
            if d_sam < min_lig_sam:
                continue

        # 4. 不与已有 T3Q 原子重叠
        if existing_ligands:
            d_ligs = [minimum_atom_distance(candidate_coords, placed_coords)
                      for placed_coords in existing_ligands]
            if min(d_ligs) < min_lig_lig:
                continue

        return pos

    raise RuntimeError(f"无法在 {max_attempts} 次尝试内找到合适位置。请尝试：\n"
                       f"  - 减小 N_LIGANDS\n"
                       f"  - 增大 BOX_BUFFER\n"
                       f"  - 减小 POCKET_EXCLUDE_RADIUS\n"
                       f"  - 减小 MIN_LIG_LIG_DIST")

def main():

        print("用法: python3 setup_multi_T3Q.py <SeNMT.pdb> <SAM_ante.mol2> <T3Q_ante.mol2> <pocket_center_x,y,z> [N_LIGANDS]")
        print("示例: python3 setup_multi_T3Q.py SeNMT.pdb SAM_ante.mol2 T3Q_ante.mol2 15.0,20.0,25.0 5")
        print()
        print("说明:")
        print("  - SAM_ante.mol2 的坐标必须已与 SeNMT.pdb 对齐（辅因子在口袋中）")
        print("  - T3Q_ante.mol2 会被复制 N 份，随机散布在溶剂中")
        print("  - pocket_center 用于排除初始放置区域，让 T3Q 从远处扩散进入")
        sys.exit(1)

    prot_file = sys.argv[1]
    sam_file = sys.argv[2]
    lig_file = sys.argv[3]
    pocket_center = np.array([float(x) for x in sys.argv[4].split(',')])
    N_LIGANDS = int(sys.argv[5]) if len(sys.argv) > 5 else 5

    if pocket_center.shape != (3,):
        raise ValueError("pocket_center 必须是三个逗号分隔的坐标，例如 15.0,20.0,25.0")
    if N_LIGANDS < 1:
        raise ValueError("N_LIGANDS 必须至少为 1")

    print("=" * 60)
    print("SeNMT + SAM + N×T3Q 多配体体系构建")
    print("=" * 60)
    print()

    print(f"[1/5] 读取蛋白: {prot_file}")
    prot_coords, _ = read_pdb_coords(prot_file)

    print(f"[2/5] 读取 SAM (辅因子): {sam_file}")
    sam_coords, sam_atoms = read_mol2(sam_file)

    print(f"[3/5] 读取 T3Q (被研究配体): {lig_file}")

    prot_center, prot_radius = get_center_and_radius(prot_coords)

    box_center = prot_center

    print("体系信息:")
    print(f"  蛋白原子数:     {len(prot_coords)}")
    print(f"  SAM 原子数:     {len(sam_coords)}")
    print(f"  T3Q 原子数:     {len(lig_coords)}")
    print(f"  蛋白中心:       [{prot_center[0]:.2f}, {prot_center[1]:.2f}, {prot_center[2]:.2f}]")
    print(f"  蛋白半径:       {prot_radius:.2f} Å")
    print(f"  溶剂盒子大小:   {box_size:.2f} Å (buffer={BOX_BUFFER} Å)")
    print(f"  口袋中心:       [{pocket_center[0]:.2f}, {pocket_center[1]:.2f}, {pocket_center[2]:.2f}]")
    print(f"  口袋排除半径:   {POCKET_EXCLUDE_RADIUS} Å")
    print(f"  T3Q 数量:       {N_LIGANDS}")
    print()

    # 随机放置 T3Q
    print(f"[4/5] 随机放置 {N_LIGANDS} 个 T3Q...")
    ligand_positions = []
    placed_ligand_coords = []
    lig_com = np.mean(lig_coords, axis=0)

        pos = generate_random_position(
            box_center=box_center,
            box_size=box_size,
            pocket_center=pocket_center,
            pocket_radius=POCKET_EXCLUDE_RADIUS,
            ligand_coords=lig_coords,
            ligand_center=lig_com,
            existing_ligands=placed_ligand_coords,
            prot_coords=prot_coords,

        outfile = f"T3Q_pos{i+1}.pdb"

        d_to_sam = minimum_atom_distance(new_coords, sam_coords)
        print(f"  T3Q {i+1:2d} (单体检查 PDB 使用残基号 1): 到口袋 {d_to_pocket:5.1f} Å | 到 SAM {d_to_sam:5.1f} Å | 位置 [{pos[0]:7.2f}, {pos[1]:7.2f}, {pos[2]:7.2f}]")

    print("[5/5] 生成 tleap 输入文件...")
    tleap_file = "tleap_multi_T3Q.in"

    with open(tleap_file, 'w') as f:
        f.write("# ============================================================\n")
        f.write("# tleap_multi_T3Q.in\n")
        f.write("# SeNMT + SAM (辅因子) + N×T3Q (随机溶剂配体)\n")
        f.write("# ============================================================\n\n")

        f.write("# --- 力场 ---\n")
        f.write("source leaprc.protein.ff19SB\n")
        f.write("source leaprc.gaff2\n")
        f.write("source leaprc.water.tip3p\n\n")

        f.write("# --- 配体参数 ---\n")
        f.write("loadamberparams SAM.frcmod\n")
        f.write("loadamberparams T3Q_ante.frcmod\n\n")

        f.write("# --- 加载分子 ---\n")
        f.write("# 蛋白\n")
        f.write(f"rec = loadpdb {leap_quote(prot_file)}\n\n")

        f.write("# SAM 辅因子（已对齐到口袋）\n")
        f.write(f"SAM = loadmol2 {leap_quote(sam_file)}\n\n")

        f.write("# T3Q 配体模板\n")
        f.write(f"T3Q = loadmol2 {leap_quote(lig_file)}\n\n")

        f.write("# --- 中和 ---\n")
        f.write("addions complex Na+ 0\n")

3. LiGaMD 模拟流程

LiGaMD 分为两个阶段：

Job 1：conventional MD + GaMD Equilibration

先进行常规 MD 采样势能面，再进行 GaMD 平衡。总步数 nstlim = ntcmd + nteb

Job 2：GaMD Production

正式 GaMD 产出模拟，使用 Job 1 得到的提升势参数。

阶段定义

0→ntcmd 为常规阶段，前 ntcmdprep 步用于准备；ntcmd→ntcmd+nteb 为加偏置平衡，前 ntebprep 步用于准备。准备阶段包含在 ntcmd/nteb 内部。Job2 读取保存的偏置参数与带速度的 restart，只采集固定偏置生产阶段；需保留原版本实际输出的 GaMD restart 文件名，不能重新拟合偏置后假装连续动力学。

4. 关键参数说明

参数含义
igamd=11启用 LiGaMD_Dual（配体非键能及体系剩余势能双提升）
iE=1阈值能量 E 的选择：1 为下界；iEP/iED 可分别覆盖
irest_gamd=0/1Job1=0（新模拟），Job2=1（续接）
ntcmd常规 MD 采样步数（Job1）
ntebGaMD 平衡步数（Job1）
ntave势能统计更新间隔，推荐值为体系总原子数的 4 倍
ntcmdprep / ntebprep准备阶段步数
sigma0P / sigma0D第一/第二提升势的标准差上限；LiGaMD_Dual 中对应配体非键能/体系剩余势能
ibblig=1启用配体自动识别（结合/游离）
atom_p / atom_l蛋白参考原子的序号，以及单个配体内部从 1 开始的原子序号；按最终拓扑核对，不能用全体系配体原子编号替代 atom_l
dblig结合/游离配体的距离阈值 (Å)
nlig=6体系中配体总数（1 结合 + 5 游离）
timask1 / scmask1指定结合在活性位点的配体（如 :239）
timask2 / scmask2一般为空值
重要约束

ntave 推荐值为体系总原子数的 4 倍（如总原子数 100000，则 ntave=400000）
ntcmd 和 nteb 必须是 ntave 的整数倍，以保证统计势能同步更新
Job1 总步数：nstlim = ntcmd + nteb；ntcmdprep 和 ntebprep 包含在各自阶段内部，不另行相加。输入中 __FILL_...__ 是待核对的最终拓扑编号，替换后才可运行。

5. 模拟质量初步检查

5.1 基本诊断

  • 配体是否发生了多次结合→解离事件？（检查独立重复、有效事件数与不确定度，不能用固定次数保证收敛）
  • 蛋白结构是否保持稳定？（骨架 RMSD 及口袋结构随时间无异常漂移；阈值按体系确定）
  • 模拟时间是否充足？（通常需要数百 ns 到数 μs）
  • 能量输出是否正常？（无 NaN、无温度漂移）
  • 高斯偏置参数是否合理？（检查 igamd 输出文件）

7. 重加权分析（Reweighting）

仅分析偏置参数固定后的生产阶段。令 ΔV 为该帧所有提升势之和（kcal/mol），β=1/(kBT)，归一化指数重加权为：

$$\langle O\rangle_0=\frac{\langle Oe^{\beta\Delta V}\rangle_b}{\langle e^{\beta\Delta V}\rangle_b}$$

AMBER 默认日志为 gamd.log（可由 -gamdlog 改名）。列格式必须查阅当前版本及输出表头；不要假定 igamd.dat 的第三列就是总偏置。按 MD 步号将距离与两项偏置对齐，并导出 step,distance_A,boost_kcal_mol 三列 CSV。CPPTRAJ 帧号必须先按轨迹起始步与 ntwx 映射为 MD 步号。相同行数不等于数据已经对齐。

7.1 归一化指数估计（用于诊断）

# 数值稳定不能消除少数高权重帧造成的统计不收敛。

7.2 二阶累积量近似 PMF

每个反应坐标区间分别计算提升势均值和方差；当条件提升势分布接近高斯、采样充分时，采用：

$$F_i\approx-\beta^{-1}\ln(n_i/\Delta\xi_i)-\langle\Delta V\rangle_i-\frac{\beta}{2}\mathrm{Var}(\Delta V)_i+C$$

该式保留实际区间占比和偏置均值。零采样或低采样区间输出 NaN，不使用任意小概率制造有限能垒。需检查条件分布非高斯性、时间相关性、分块与独立重复收敛。

8. 动力学统计与 PMF 解读

8.1 偏置轨迹中的表观事件速率

下面仅计算偏置模拟的事件数/状态总暴露时间，不能直接作为真实 k_off、k_on 或 K_d。帧间隔为 dt(ps)×ntwx/1000 ns；Job2 示例为 0.002×10000/1000=0.02 ns。结合速率还需要与事件定义匹配的游离配体浓度 [L]。

$$k_{off}^{b}=N_{unbind}/T_{bound}^{b},\qquad k_{on}^{b}=N_{bind}/(T_{unbound}^{b}[L])$$

Python
from analysis.ligamd_analysis import estimate_biased_kinetics
stats = estimate_biased_kinetics(states, frame_dt_ns=0.02,
                               ligand_concentration_M=None)
print(stats)  # 单位s^-1；给定浓度时k_on单位M^-1 s^-1
# 两态马尔可夫/均匀帧间隔只是统计模型假设；末尾区间计入暴露时间。

真实动力学需要独立的方法验证和动力学重加权，例如原论文采用的 TST/Kramers 分析；不能简单用平均提升势的指数乘以停留时间。无事件只说明采样中未观察到事件，不证明真实速率为零。

8.2 PMF 水平差与标准结合自由能

PMF(unbound)−PMF(bound) 仅表示该坐标上的游离减结合水平差，接近解离方向，不能标为标准结合自由能。径向坐标还涉及 4πr² 的几何因子；标准 ΔG_bind 必须按状态定义积分并处理约束与标准态体积，不是简单反转符号就能得到。

def find_intermediate_candidates(distance, energy, vbias, 
                                     bound_cutoff=5, unbound_cutoff=10):
    """选择中间距离区间的高势能候选构象；不是动力学过渡态判定"""
    ts_mask = (distance > bound_cutoff) & (distance < unbound_cutoff)
    ts_energy = energy[ts_mask]
    ts_frames = np.where(ts_mask)[0]
    n_ts = min(10, len(ts_energy))
    if n_ts == 0:
        return np.array([], dtype=int)
    top_indices = np.argsort(ts_energy)[-n_ts:]
    return ts_frames[top_indices]

def analyze_contacts_per_state(trajectory, topology, states, ligand_residue='LIG'):
    """Return protein-residue contact frequencies in biased bound frames (not reweighted)."""
    import numpy as np
    import mdtraj as md
    traj = md.load(trajectory, top=topology)
    states = np.asarray(states)
    if states.shape != (traj.n_frames,):
        raise ValueError('states must align with trajectory frames')
    ligand_residues = [r.index for r in traj.topology.residues if r.name == ligand_residue]
    if len(ligand_residues) != 1:
        raise ValueError('Select one physical ligand; split multi-ligand analysis')
    protein_residues = [r.index for r in traj.topology.residues if r.is_protein]
    bound_frames = np.flatnonzero(states == 1)
    if not protein_residues or not bound_frames.size:
        raise ValueError('Protein residues and bound frames required')
    pairs = np.array([(r, ligand_residues[0]) for r in protein_residues], dtype=int)
    distances_nm, pairs = md.compute_contacts(traj.slice(bound_frames),
        contacts=pairs, scheme='closest-heavy', periodic=True)
    frequency = (distances_nm < 0.45).mean(axis=0)
    return pairs[:,0], frequency  # topology residue indices, zero-based
# MDTraj returns nm; 0.45 nm = 4.5 A. Mapping to residue labels needs topology.residue(index).

2. gmx_LIE

Linear Interaction Energy (LIE) 方法通过线性响应近似计算结合自由能，通常成本较低，但其经验参数的适用性与误差需针对体系检验，不能给出普遍的精度排序。

2.1 LIE 原理

ΔG_bind = α(⟨V_bound^vdW⟩ − ⟨V_free^vdW⟩) + β(⟨V_bound^elec⟩ − ⟨V_free^elec⟩) + γ

其中：

  • ⟨V_bound^vdW/elec⟩：复合体中蛋白-配体相互作用能
  • ⟨V_free^vdW/elec⟩：游离配体在溶剂中的相互作用能（需单独模拟）
  • α, β, γ：经验参数；数值应依据所用 LIE 参数化和目标体系的文献或校准确定，常见默认值不是普适精度保证。

import numpy as np

def mean_xvg(path):
    data = np.loadtxt(path, comments=('#', '@'))
    if data.ndim != 2 or data.shape[1] < 2:
        raise ValueError(f"{path} must contain time and energy columns")
    return float(np.mean(data[:, 1]))  # GROMACS energy: kJ/mol

# 每个文件都应是相应能量组对的时间序列，并先剔除未平衡区间
vdw_bound = mean_xvg('vdw_bound.xvg')   # LIG-ENV, bound ensemble
vdw_free = mean_xvg('vdw_free.xvg')     # LIG-SOL, free ligand in water
elec_bound = mean_xvg('elec_bound.xvg') # LIG-ENV, bound ensemble
elec_free = mean_xvg('elec_free.xvg')   # LIG-SOL, free ligand in water

delta_vdw = vdw_bound - vdw_free
delta_elec = elec_bound - elec_free

# 示例经验系数；应按所采用的 LIE 参数化/文献选取或校准
alpha = 0.18
beta = 0.50
gamma = 0.0  # kJ/mol；仅在所选参数化定义了该偏置项时使用
delta_G_kJ = alpha * delta_vdw + beta * delta_elec + gamma

print(f"Δ⟨V_vdW⟩ = {delta_vdw:.2f} kJ/mol")
print(f"Δ⟨V_elec⟩ = {delta_elec:.2f} kJ/mol")
print(f"ΔG_bind (LIE) = {delta_G_kJ:.2f} kJ/mol")
print(f"ΔG_bind (LIE) = {delta_G_kJ / 4.184:.2f} kcal/mol")

3. 结合自由能计算对比

方法主要适用条件与限制
MM/PBSA、MM/GBSA端点近似；检查采样、溶剂模型、熵与受体/配体分割，需针对目标任务验证

#!/usr/bin/env python3
"""
gmx_automation.py - GROMACS 自动化脚本
"""
import os
import subprocess
import numpy as np
import matplotlib.pyplot as plt

class GromacsWorkflow:
    def __init__(self, project_name="md_project"):
        self.project = project_name
        self.workdir = os.getcwd()
        
    def run_command(self, cmd, input_text=None):
        """运行 GROMACS 命令"""
        print(f"运行: {cmd}")
        if input_text:
            proc = subprocess.Popen(cmd, shell=True, 
                                   stdin=subprocess.PIPE,
                                   stdout=subprocess.PIPE,
                                   stderr=subprocess.PIPE)
            stdout, stderr = proc.communicate(input=input_text.encode())
        else:
            proc = subprocess.run(cmd, shell=True, capture_output=True)
            stdout, stderr = proc.stdout, proc.stderr
        
        if proc.returncode != 0:
            print(f"错误: {stderr.decode()}")
            return False
        return True
    
    def setup_system(self, pdb_file, force_field="amber99sb-ildn"):
        """设置体系"""
        print("=== 设置体系 ===")
        
        # pdb2gmx
        cmd = f"gmx pdb2gmx -f {pdb_file} -o protein.gro -ff {force_field} -water spce -ignh"
        self.run_command(cmd)
        
        # editconf
        cmd = "gmx editconf -f protein.gro -o conf_box.gro -d 1.0 -bt cubic"
        self.run_command(cmd)
        
        # solvate
        cmd = "gmx solvate -cp conf_box.gro -cs spc216.gro -o conf_solv.gro -p topol.top"
        self.run_command(cmd)
        
        print("体系设置完成")
    
    def run_md(self, nsteps=5000000):
        """运行 MD 模拟"""
        print("=== 运行 MD ===")
        
        # 能量最小化
        self.run_command("gmx grompp -f em.mdp -c conf_ions.gro -p topol.top -o em.tpr")
        self.run_command("gmx mdrun -deffnm em")
        
        # NVT
        self.run_command("gmx grompp -f nvt.mdp -c em.gro -r em.gro -p topol.top -o nvt.tpr")
        self.run_command("gmx mdrun -deffnm nvt")
        
        # NPT
        self.run_command("gmx grompp -f npt.mdp -c nvt.gro -r nvt.gro -t nvt.cpt -p topol.top -o npt.tpr")
        self.run_command("gmx mdrun -deffnm npt")
        
        # MD
        self.run_command(f"gmx grompp -f md.mdp -c npt.gro -t npt.cpt -p topol.top -o md.tpr")
        self.run_command("gmx mdrun -deffnm md")
        
        print("MD 完成")
    
    def analyze_rmsd(self):
        """分析 RMSD"""
        print("=== 分析 RMSD ===")
        
        # 运行 gmx rms
        cmd = "gmx rms -s md.tpr -f md.xtc -o rmsd.xvg -tu ns"
        self.run_command(cmd, input_text="4\n4\n")

        data = np.loadtxt('rmsd.xvg', comments=['#', '@'])
        time = data[:, 0]
        rmsd = data[:, 1]
        
        # 绘图

        plt.plot(time, rmsd * 10, 'b-', linewidth=1)  # nm → Å
        plt.xlabel('Time (ns)')
        plt.ylabel('RMSD (Å)')
        plt.title('Protein RMSD')
        plt.grid(True, alpha=0.3)
        plt.savefig('rmsd_plot.png', dpi=300)
        
        print(f"平均 RMSD: {np.mean(rmsd)*10:.2f} Å")
        return time, rmsd

# 二面角
measure dihed [list $a1 $a2 $a3 $a4]

# 质心
measure center $sel weight mass

# 回转半径
measure rgyr $sel

# ===== 结构量 =====
# RMSD（相对于参考）
measure rmsd $sel $ref

# RMSF（均方根涨落）；以下假设轨迹已按参考结构对齐
set last_frame [expr {[molinfo top get numframes] - 1}]
set rmsf_list [measure rmsf $sel first 0 last $last_frame step 1]

# ===== 对齐 =====
# 计算最优叠合矩阵
set mat [measure fit $sel $ref]
$sel move $mat

2.1 measure energy（基于 CHARMM 力场）

# measure energy 按 CHARMM 函数形式和显式参数计算单个能量项，不读取模拟器的总能量
# 示例：两个原子须为已参数化的键；将 k 和 x0 替换为该键的实际参数
set sel [atomselect top "index 0 1"]

2.2 从 SMD 日志提取力

VMD Tcl — 提取 SMD 力
# 仅适用于下述 NAMD SMD 日志格式；AMBER 需按原生输出另写解析器
# NAMD 日志中 SMD 行格式：SMD timestep x y z fx fy fz

set logfile [open "smd_output.log" r]
set outfile [open "force_time.dat" w]

# 拉伸方向单位向量
set nx 0.0; set ny 0.0; set nz 1.0

while {[gets $logfile line] != -1} {
    if {[lindex $line 0] eq "SMD"} {
        set timestep [lindex $line 1]
        set fx [lindex $line 5]
        set fy [lindex $line 6]
        set fz [lindex $line 7]
        # 投影到拉伸方向
        set f_proj [expr $nx*$fx + $ny*$fy + $nz*$fz]
        puts $outfile "$timestep $f_proj"
    }
}

close $logfile
close $outfile

2.3 逐帧导出质心轨迹（坐标本身不是力）

VMD Tcl — 自定义力计算

set outfile [open "ligand_com.dat" w]

for {set i 0} {$i < $nframes} {incr i} {
    $sel frame $i

    puts $outfile "$i [lindex $com 0] [lindex $com 1] [lindex $com 2]"
}

# 或在有完整力场参数时由势能对坐标求梯度。

3. Tcl 脚本自动化

3.1 批量轨迹分析脚本

VMD Tcl — 批量分析脚本
# analyze_trajectory.tcl
# 用法：vmd -dispdev text -e analyze_trajectory.tcl

mol new system.psf
mol addfile trajectory.dcd waitfor all

set nframes [molinfo top get numframes]
set outfile_rmsd [open "rmsd_time.dat" w]
set outfile_rgyr [open "rgyr_time.dat" w]

# 参考结构（第一帧）
set ref [atomselect top "protein and name CA" frame 0]
set sel [atomselect top "protein and name CA"]

for {set i 0} {$i < $nframes} {incr i} {
    $sel frame $i
    $sel move [measure fit $sel $ref]
    
    # RMSD
    set rmsd [measure rmsd $sel $ref]
    puts $outfile_rmsd "$i $rmsd"
    
    # 回转半径
    set rgyr [measure rgyr $sel]
    puts $outfile_rgyr "$i $rgyr"
}

close $outfile_rmsd
close $outfile_rgyr
puts "分析完成！"
quit

3.2 能量随时间变化脚本

VMD Tcl — 能量轨迹
# 先从模拟器导出实际能量项，例如 GROMACS：
# gmx energy -f md.edr -o potential.xvg
# 在交互菜单中选择 Potential；其他模拟器需按其原生日志格式解析

set infile [open "potential.xvg" r]
set outfile [open "energy_profile.dat" w]
puts $outfile "# time_ps  Potential_kJ_mol"

while {[gets $infile line] != -1} {
    set line [string trim $line]
    if {$line eq "" || [string index $line 0] eq "#" || [string index $line 0] eq "@"} {
        continue
    }
    set fields [regexp -all -inline {\S+} $line]
    if {[llength $fields] >= 2} {
        puts $outfile "[lindex $fields 0] [lindex $fields 1]"
    }
}

close $infile
close $outfile
puts "已写出模拟器记录的势能时间序列"
quit

3. 拓扑生成与体系构建

3.1 pdb2gmx — 生成拓扑

bash — 蛋白质拓扑生成
# 使用 AMBER99SB-ILDN 力场，SPC/E 水模型
gmx pdb2gmx -f protein.pdb -o protein_processed.gro \
            -ff amber99sb-ildn -water spce -ignh

# 参数说明：
# -ff        力场选择（amber99sb-ildn, charmm36, oplsaa 等）
# -water     水模型（spce, tip3p, tip4p 等）
# -ignh      忽略 PDB 中的氢原子（重新添加）
# -his       指定组氨酸质子化态（HID/HIE/HIP）

3.2 配体参数化

bash — 使用 ACPYPE 生成配体拓扑
# 方式一：从 mol2 文件生成（AMBER GAFF 力场）
acpype -i ligand.mol2 -c bcc -a leap

# 方式二：从 PDB 文件生成
acpype -i ligand.pdb -c bcc

# 生成的文件：
# ligand_GMX.itp      — 配体拓扑包含文件
# ligand_GMX.top      — 完整拓扑文件
# posre_ligand.itp    — 位置约束文件

# 将配体拓扑合并到系统拓扑
cat ligand_GMX.itp >> topol.top
# 或在 topol.top 的 moleculetype 部分添加 #include

3.3 定义模拟盒子

bash — 盒子设置
# 创建正交盒子，距离溶质边界 1.0 nm
gmx editconf -f protein_processed.gro -o conf_box.gro \
            -d 1.0 -bt cubic

# -d    溶质到盒子边界的最小距离 (nm)
# -bt   盒子类型：cubic / dodecahedron / octahedron
#       dodecahedron 体积比 cubic 小约 29%，节省计算量

3.4 填充溶剂

bash — 溶剂化
# 填充 SPC/E 水
gmx solvate -cp conf_box.gro -cs spc216.gro \
           -o conf_solv.gro -p topol.top

# -cs   溶剂坐标文件（GROMACS 自带水模型坐标）
# -p    更新拓扑文件中的水分子数

3.5 添加离子

bash — 中和电荷 + 添加盐浓度
# 先生成 tpr 文件（用于 genion）
gmx grompp -f ions.mdp -c conf_solv.gro -p topol.top \
          -o ions.tpr

# 添加离子（中和 + 0.15 M NaCl）
gmx genion -s ions.tpr -o conf_ions.gro -p topol.top \
          -pname NA -nname CL -neutral -conc 0.15

# -neutral   中和体系净电荷
# -conc      盐浓度 (mol/L)
# -pname/-nname  正/负离子名称
提示

ions.mdp 只需包含基本参数，无需完整模拟设置。可以复制 em.mdp 并简化。

4.1 创建 MDP 文件

em.mdp — 能量最小化参数
; 能量最小化参数
integrator  = steep      ; 最速下降法
nsteps      = 50000      ; 最大步数
nstlist     = 10         ; 邻居列表更新频率

; 截断设置

nstlist         = 10

; 静电

nstlog             = 500   ; 每 500 步记录日志

4.2 运行最小化

bash — 执行能量最小化
# 预处理（生成 tpr）
gmx grompp -f em.mdp -c conf_ions.gro -p topol.top \
          -o em.tpr

# 运行模拟
gmx mdrun -v -deffnm em

# 检查势能是否收敛
gmx energy -f em.edr -o em_potential.xvg
# 选择 "Potential" → 查看势能曲线

5. 平衡与正式模拟

5.1 NVT 平衡（升温）

nvt.mdp — NVT 平衡参数
; NVT 参数模板；截断值和温控分组须与体系拓扑、所选力场相匹配
integrator    = md
nsteps        = 5000       ; 5 ps 示例，不代表已达到平衡
dt            = 0.001      ; 1 fs

; 输出
nstxout-compressed = 500
nstlog             = 500
nstenergy          = 500

; 从最小化结构开始新段：初始化 Maxwell 速度；不读取前一段速度
continuation    = no
gen_vel         = yes
gen_temp        = 300
constraint_algorithm = lincs
constraints     = all-bonds

; 邻居列表与非键相互作用（示例值须按力场要求核对）
cutoff-scheme   = Verlet
nstlist         = 20
rcoulomb        = 1.0
rvdw            = 1.0
coulombtype     = PME

; 明确启用温度耦合；仅写 tau_t/ref_temp 不会启用 thermostat
tcoupl          = V-rescale
tc-grps         = Protein Non-Protein
tau_t           = 0.1     0.1
ref_t           = 300     300

pbc             = xyz

; 可选位置约束（需要拓扑中正确 include posre.itp）
; define = -DPOSRES

5.2 NPT 平衡（恒压）

npt.mdp — NPT 平衡参数
; NPT 参数模板：保留 NVT 的力场、约束和非键模型；按同一体系参数核对
integrator    = md
nsteps        = 5000       ; 5 ps 示例，不代表已达到平衡
dt            = 0.001

; 从 NVT checkpoint 延续坐标、速度和状态；不要重新生成速度
continuation    = yes
gen_vel         = no
constraint_algorithm = lincs
constraints     = all-bonds

; 非键设置应与 NVT 和所选力场一致

nstlist         = 20
rcoulomb        = 1.0
rvdw            = 1.0
coulombtype     = PME
pbc             = xyz

; 明确温度耦合；这些参数要与 NVT 的分组保持一致

tc-grps         = Protein Non-Protein

5.3 运行平衡和正式模拟

bash — 平衡 + 生产运行
# === NVT 平衡 ===
# nvt.mdp 应显式设置 tcoupl；从 EM 坐标新起步时 gen_vel=yes、continuation=no
gmx grompp -f nvt.mdp -c em.gro -r em.gro -p topol.top \
          -o nvt.tpr
gmx mdrun -deffnm nvt

# === NPT 平衡 ===
# npt.mdp 应含目标压力耦合和温度耦合；continuation=yes、gen_vel=no 与 -t nvt.cpt 配套
gmx grompp -f npt.mdp -c nvt.gro -r nvt.gro -t nvt.cpt \
          -p topol.top -o npt.tpr
gmx mdrun -deffnm npt

# === 正式 MD 生产运行 ===
# md.mdp 需提供完整生产参数；从 npt.cpt 延续时通常设 continuation=yes、gen_vel=no，
# 并按目标系综明确选择温度/压力耦合，而不是沿用未经检查的占位文件。
gmx grompp -f md.mdp -c npt.gro -t npt.cpt -p topol.top \
          -o md.tpr
gmx mdrun -deffnm md

# 断点续跑：与本次运行使用同一 tpr 和 checkpoint
gmx mdrun -deffnm md -cpi md.cpt -append
GPU 加速

生产运行强烈建议使用 GPU：gmx mdrun -nb gpu -pme gpu -bonded gpu。多 GPU 可用 -ngpu 2 指定。

GROMACS 支持多种增强采样和自由能计算方法，包括伞形采样、MetaDynamics、ABF、SMD、TI、FEP 等。本节介绍这些方法在 GROMACS 中的实现。

📑 Gromacs 进阶导航
1. 伞形采样 (US) 2. MetaDynamics 3. ABF 自适应偏置力 4. 拉伸 MD (SMD) 5. 热力学积分 (TI) 6. 自由能微扰 (FEP)

1. 伞形采样 (Umbrella Sampling)

伞形采样通过沿反应坐标施加谐振偏置势，强制体系探索自由能面上的各个区域，最后用 WHAM 或 MBAR 合并得到 PMF。

1.1 工作流程

1. 定义反应坐标 (CV)

├── 选择集体变量（距离、角度、RMSD 等）

└── 确定 CV 范围（反应物 → 产物）

2. 生成初始构型

├── 约束优化或短 MD 将体系拉到各窗口初始位置

└── 或使用 SMD 轨迹抽取帧作为各窗口起点

3. 运行伞形采样窗口

├── 每个窗口施加不同中心位置的谐振势

└── 每窗口运行 1-10 ns

4. WHAM/MBAR 分析

└── 合并各窗口数据，得到 PMF 曲线

1.2 pull code 设置

us_window.mdp — 伞形采样参数
; 伞形采样使用 pull code；pull-ngroups 是 pull 组数（不含 absolute reference）
pull                 = yes
pull-ngroups         = 2
pull-ncoords         = 1
pull-group1-name     = Protein_residue_42
pull-group2-name     = Ligand
pull-coord1-type     = umbrella
pull-coord1-geometry = distance
pull-coord1-dim      = Y N N      ; 只使用 x 分量
pull-coord1-groups   = 1 2
pull-coord1-init     = 0.50       ; 当前窗口中心 (nm)
pull-coord1-k        = 1000.0     ; 力常数 (kJ/mol/nm²)

; index.ndx 中须定义名称完全一致的组，例如：
; [ Protein_residue_42 ]
; ...原子编号...
; [ Ligand ]
; ...原子编号...

1.3 批量窗口脚本

bash — 批量运行伞形采样窗口
#!/bin/bash
# 窗口参数
XI_MIN=0.20   # nm
XI_MAX=1.00   # nm
N_WINDOWS=20
KAPPA=1000    # kJ/mol/nm²

DX=$(echo "scale=4; ($XI_MAX - $XI_MIN) / $N_WINDOWS" | bc)

for i in $(seq 0 $N_WINDOWS); do
    XI=$(echo "scale=4; $XI_MIN + $i * $DX" | bc)
    DIR=window_${i}
    mkdir -p $DIR
    cd $DIR
    
    # 修改 mdp 中的 pull-coord1-init
    sed "s/INIT_XI/${XI}/g" ../us_template.mdp > us.mdp
    
    # 生成 tpr
    gmx grompp -f us.mdp -c ../init_${i}.gro \
              -p ../topol.top -n ../index.ndx -o us.tpr
    
    # 运行并显式输出 pull 坐标
    gmx mdrun -deffnm us -px us.pullx.xvg
    
    cd ..
done

2. MetaDynamics

MetaDynamics 通过在 CV 空间添加高斯势垒，逐步填充自由能面，使体系能够跨越能垒探索新区域。GROMACS 通过 PLUMED 插件实现。

2.1 安装 PLUMED

bash — PLUMED 安装与集成
# 复用已验证且支持PLUMED的GROMACS构建；集成/编译方式随版本变化。
# 本仓库不提供跨版本通用patch命令。
gmx mdrun -h  # 确认包含 -plumed 选项
plumed info --version
# 保存GROMACS/PLUMED具体版本、构建方式与运行参数。
# 支持接口的构建通常以命令行启用：
gmx mdrun -deffnm metad -plumed plumed.dat
# 官方示例：https://www.plumed.org/doc-v2.9/user-doc/html/cambridge.html

2.2 PLUMED 输入文件

plumed.dat — Well-Tempered MetaDynamics
# 定义集体变量
d: DISTANCE ATOMS=100,200   # 原子 100 和 200 的距离

# Well-Tempered MetaDynamics
metad: METAD ARG=d SIGMA=0.05 HEIGHT=1.2 BIASFACTOR=10 TEMP=300 PACE=500 FILE=HILLS
# SIGMA: 高斯宽度 (nm)  HEIGHT: 初始高斯高度 (kJ/mol)
# BIASFACTOR: 偏置因子  PACE: 每 500 步添加高斯

# 输出
PRINT ARG=d,metad.bias STRIDE=100 FILE=COLVAR

3. ABF 自适应偏置力

Adaptive Biasing Force (ABF) 累积估计集体变量方向的平均力，并逐步施加补偿偏置；PMF 是否可信仍取决于采样覆盖、力估计和收敛检查。GROMACS 需使用编译启用了 Colvars 的版本。

3.1 Colvars 配置

colvar.inp — ABF 配置
# GROMACS 后端使用原生单位：距离 nm、能量 kJ/mol
units gromacs

# 两个 atomNumbers 必须对应当前拓扑/坐标中的原子编号
colvar {
    name distance_cv
    distance {
        group1 { atomNumbers 100 }
        group2 { atomNumbers 200 }
    }
    lowerBoundary 0.20
    upperBoundary 1.00
    width 0.01   # nm；该范围对应 80 个网格间隔
}

# ABF 的 colvars 在此引用上面定义的 CV；网格边界/宽度属于 colvar 块
abf {
    name abf
    colvars distance_cv
    fullSamples 200
    outputFreq 1000
}

# Colvars 将轨迹写为 <GROMACS 输出前缀>.colvars.traj；
# ABF 的 PMF/梯度/计数文件按输出前缀命名

3.2 GROMACS MDP 设置

abf.mdp — ABF 参数
; 使用编译启用了 Colvars 的 GROMACS

colvars-configfile = colvar.inp

; 常规 MD 参数

; 明确启用温度耦合

5. 热力学积分 (Thermodynamic Integration)

TI 通过沿耦合参数 λ 积分平均力差 ⟨∂H/∂λ⟩，计算两个状态之间的自由能差。GROMACS 内置支持 TI。

[ atoms ]

    2    OH    1      LIG     O1     2    -0.5    16.0   OH   -0.7     16.0

5.3 运行与分析

bash — TI 运行与积分
# TI：为 0..10 共 11 个 λ 状态分别生成输入并运行
for i in $(seq 0 10); do
    mkdir -p "ti_$i"
    sed "s/^init-lambda-state.*/init-lambda-state = $i/" ti.mdp > "ti_$i.mdp"
    gmx grompp -f "ti_$i.mdp" -c init.gro -p topol.top \
              -o "ti_$i/ti.tpr" -n index.ndx
    gmx mdrun -s "ti_$i/ti.tpr" -deffnm "ti_$i/ti" \
              -dhdl "ti_$i/ti.dhdl.xvg"
done

# TI 对各窗口的平均 dH/dlambda 随 lambda 数值积分；以下用梯形规则演示
# 该均值示例不估计统计误差，正式结果还应做分块误差和收敛分析
python - <<'PY'
lambdas = [i / 10 for i in range(11)]
means = []
for i in range(11):
    values = []
    with open(f"ti_{i}/ti.dhdl.xvg", encoding="utf-8") as f:
        for line in f:
            line = line.strip()
            if not line or line[0] in "#@":
                continue
            values.append(float(line.split()[1]))
    means.append(sum(values) / len(values))
delta_g = sum((lambdas[i + 1] - lambdas[i]) * (means[i] + means[i + 1]) / 2
              for i in range(10))
print(f"TI ΔG = {delta_g:.3f} kJ/mol")
PY
# gmx bar 是独立的 BAR 估计器，不是 TI 数值积分程序

6. 自由能微扰 (Free Energy Perturbation)

FEP 通过改变哈密顿量获得不同 λ 状态的样本；BAR 用相邻状态的能量差估计自由能，TI 则对各状态的平均 ∂H/∂λ 数值积分。两者是不同的自由能估计方法。

6.1 相对结合自由能计算

热力学循环

ΔΔG_bind = ΔG_complex(B→A) - ΔG_solvent(B→A)

= ΔG_water(B→A) - ΔG_protein(B→A)

计算步骤

1. 在溶剂中：计算配体 B→A 的 ΔG_solvent

2. 在蛋白中：计算配体 B→A 的 ΔG_complex

3. 差值即为相对结合自由能 ΔΔG

6.2 GROMACS FEP 设置

fep.mdp — FEP 参数
; BAR/FEP 窗口模板；20 个间隔对应 21 个 λ 状态，按体系增加采样
free-energy             = yes
init-lambda-state       = 0       ; 运行循环会替换为当前窗口索引
fep-lambdas             = 0.00 0.05 0.10 0.15 0.20 0.25 0.30 0.35 0.40 0.45 0.50 0.55 0.60 0.65 0.70 0.75 0.80 0.85 0.90 0.95 1.00
calc-lambda-neighbors   = 1       ; 为 BAR 计算相邻 λ 状态的能量差
nstdhdl                 = 100
separate-dhdl-file      = yes

; 软核势参数（按实际变换调整）
sc-alpha    = 0.5
sc-power    = 1
sc-sigma    = 0.3

; 示例采样长度；需按收敛情况增加
nsteps      = 50000

6.3 BAR/MBAR 分析

bash — BAR 分析
# BAR/FEP：每个窗口需有相邻态能量差输出；这里逐状态生成 21 个窗口
for i in $(seq 0 20); do
    mkdir -p "fep_$i"
    sed "s/^init-lambda-state.*/init-lambda-state = $i/" fep.mdp > "fep_$i.mdp"
    gmx grompp -f "fep_$i.mdp" -c init.gro -p topol.top \
              -o "fep_$i/fep.tpr" -n index.ndx
    gmx mdrun -s "fep_$i/fep.tpr" -deffnm "fep_$i/fep" \
              -dhdl "fep_$i/fep.dhdl.xvg"
done

# 输入各窗口的 dhdl.xvg；BAR 用这些交叉态 ΔH 样本估计自由能差
gmx bar -f fep_0/fep.dhdl.xvg fep_1/fep.dhdl.xvg fep_2/fep.dhdl.xvg \
       fep_3/fep.dhdl.xvg fep_4/fep.dhdl.xvg fep_5/fep.dhdl.xvg \
       fep_6/fep.dhdl.xvg fep_7/fep.dhdl.xvg fep_8/fep.dhdl.xvg \
       fep_9/fep.dhdl.xvg fep_10/fep.dhdl.xvg fep_11/fep.dhdl.xvg \
       fep_12/fep.dhdl.xvg fep_13/fep.dhdl.xvg fep_14/fep.dhdl.xvg \
       fep_15/fep.dhdl.xvg fep_16/fep.dhdl.xvg fep_17/fep.dhdl.xvg \
       fep_18/fep.dhdl.xvg fep_19/fep.dhdl.xvg fep_20/fep.dhdl.xvg \
       -o bar_results.xvg -oi bar_energy.xvg

# 输出 bar_results.xvg 包含：
# λ值   ΔG(kJ/mol)   误差

# PyMBAR 4 示例：文件必须由预处理步骤生成并核验
# reduced_potentials.npz 内含：
#   u_kn: 每个采样帧在每个 λ 态下的 reduced potential，shape=(K, sum(N_k))
#   N_k: 各 λ 态贡献的样本数，shape=(K,)
#   temperature_K: 与 u_kn 定义一致的温度（K）
python -c "
import numpy as np
import pymbar

with np.load('reduced_potentials.npz', allow_pickle=False) as data:
    u_kn = np.asarray(data['u_kn'], dtype=float)
    N_k = np.asarray(data['N_k'], dtype=int)
    temperature_K = float(data['temperature_K'])

if u_kn.ndim != 2 or N_k.ndim != 1:
    raise ValueError('u_kn must be 2D and N_k must be 1D')
if u_kn.shape != (N_k.size, int(N_k.sum())) or np.any(N_k <= 0):
    raise ValueError('u_kn shape must equal (K, sum(N_k)); every state needs samples')
if not np.all(np.isfinite(u_kn)) or temperature_K <= 0:
    raise ValueError('u_kn and temperature_K must be finite and valid')

mbar = pymbar.MBAR(u_kn, N_k)
result = mbar.compute_free_energy_differences()
kB = 0.00831446261815324  # kJ mol^-1 K^-1
delta_g = result['Delta_f'][0, -1] * kB * temperature_K
sigma_g = result['dDelta_f'][0, -1] * kB * temperature_K
print(f'ΔG = {delta_g:.3f} ± {sigma_g:.3f} kJ/mol')
"
# Δf 和 dDelta_f 是无量纲 reduced free energies/不确定度；
# 转为能量需乘 kB*T。构造 u_kn 必须对所有采样帧计算各 λ 态的势能，不能把 dhdl 列直接当作 u_kn。

6.4 与 TI 的对比

特性TIFEP / BAR / MBAR
估计量对 λ 积分系综平均的 ⟨∂H/∂λ⟩FEP 用指数平均；BAR 用相邻态双向能量差；MBAR 联合多个态的 reduced potentials
状态/窗口数按积分精度、采样收敛和误差诊断增加；无通用固定数按相邻态重叠、有效样本和误差诊断布点；无通用固定数
统计可靠性取决于 λ 网格、每态采样及数值积分收敛取决于态间重叠和双向/多态有效样本；MBAR 不会弥补缺乏重叠
统计误差需结合时间相关性做分块或重复模拟估计器可给统计不确定度；仍需检查自相关、重叠及分块/重复结果
系统误差两类方法都不由统计误差自动覆盖力场、模型或有限采样偏差两类方法都不由统计误差自动覆盖力场、模型或有限采样偏差
